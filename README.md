# 🌍 Three.js 3D 地球（Three.js-3D-Earth）

**🌐 语言 / Language：** [中文](README.md) | [English](README.en.md)

> 🕹️ **在线预览 / Live Demo**：<https://ZGdadong.github.io/Three.js-3D-Earth/> （GitHub Pages，需在仓库 Settings → Pages 开启后生效）

> ⭐ 这个项目对你有帮助的话，使用前记得先点个 **Star** 支持一下～

一个用 **Three.js** 实现的**真实风格 3D 地球**，带有动态**昼夜切换**、**平滑晨昏线**、**云层**、**大气辉光**、**星空闪烁**、**法线贴图地形细节**、**城市光点标注**，以及一个**从北极到南极单向扫描的能量波护罩**。

<img width="1275" height="702" alt="Demo" src="https://github.com/user-attachments/assets/0d2080a9-b1b8-4f26-b8ac-dd49d6275396" />


> 本场景刻意**移除了太阳和月亮**，只保留光照与地球本体；所有参数都可通过页面右侧的 `lil-gui` 面板实时调节，并支持**保存/载入/导出/导入**。

---

## ✨ 特性

- **昼夜切换 + 平滑晨昏线**：基于自定义 Shader 的白天/黑夜贴图混合，`smoothstep` 产生柔和的晨昏过渡带。
- **时段化光照**：区分 正午 / 黄昏 / 黎明 / 夜晚 —— 正午亮、黄昏/黎明带金色暖调、夜晚显示城市灯光。
- **法线贴图**：叠加在光照上，让地形有立体起伏（尤其黄昏/黎明低角度光照下最明显）。
- **云层**：独立球体，随光照受光、缓慢漂移、可调不透明度。
- **大气辉光**：背面菲涅尔蓝边，亮度可调。
- **星空**：旋转变动 + 上下摇摆 + **随机透明度闪烁**。
- **护罩 · 能量波**：地球外围的八边形网状护罩，一道能量波按设定方向（北极→南极 / 南极→北极）、设定周期、单次时长扫描，只有波经过的地方才点亮显示。
- **城市标注**：北京/上海/东京/纽约/伦敦/悉尼/开罗/里约 光点标签。
- **动态飞线**：多组 **1 起点 + n 终点** 的飞线（轨道管 + 流动彗星），终点城市有**圆形扩散波**；可配置颜色 / 形状（弧线高度、彗星长度粗细）/ 起点终点（JSON），不显示城市名。
- **参数面板**：`lil-gui` 几乎全参数可调。
- **参数持久化**：保存到浏览器 `localStorage`，刷新自动恢复；支持导出/导入 JSON、恢复默认。
- **多语言（i18n）**：界面全量多语言（界面文本 / lil-gui 面板 / 城市标注 / 飞线表格），`Languages/` 下每语言一个 JSON，右上角下拉即时切换，缺失 key 自动回退中文。
- **中国地图 · 省市下钻**：右上角一键在「地球」与「中国地图」之间切换，也可以**直接点击地球上的中国**——悬停高亮并浮出「中国」提示，点击经云带过渡切入中国地图。GeoJSON 挤出式省级行政区，区域用**渐变 + 辉光**自定义材质（底部深蓝 → 顶部青蓝），青色发光边界线；**悬停上浮 + 高亮并显示名称**，单击钻入该省（展示下辖区划），双击 / 左上角「返回」回到全国。底部为**发光渐变圆盘 + 栅格 + 两圈可带缺口的旋转圆环**，全图带**从下到上的扫描能量波**。离线打包在 `data/geojson/`，无需联网；右侧 lil-gui 可调辉光 / 悬浮 / 圆环颜色·透明度·宽度·缺口 / 扫描波。
- **画布录屏**：右下角「🎬 录制」把 WebGL 画布实时录成 **WebM/VP9** 视频（视觉无损 + 低占用），画质档可选 **高画质 / 均衡 / 高压缩**；停止后一键下载。地球与中国地图两个视图都能录。

## 🚀 运行方式

浏览器用 `file://` 直接打开会因安全策略无法加载本地贴图，因此需要启动一个本地静态服务器。

在项目根目录执行任一：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node 的 (npx) http-server / serve
npx serve -l 8080
```

然后访问 **<http://127.0.0.1:8080/index.html>** 即可。

## 🌐 多语言（i18n）

界面全量支持多语言，语言包放在根目录的 `Languages/` 文件夹下，每语言一个 JSON 文件。

### 一、语言包放哪里

**`Languages/`** 文件夹，每个语言一个 JSON 文件：

```
Languages/
├─ zh-CN.json            中文
├─ en-US.json            English
└─ 语言代码说明.txt      BCP 47 语言标签说明 + 新增语言步骤
```

> Web 项目直接从 `./Languages/` 按需加载对应文件，无需复制到输出目录；部署时把整个 `Languages/` 文件夹一起放到站点根目录即可。

### 二、语言包结构

```json
{
  "code": "zh-CN",                       // 语言代码（BCP 47，见「语言代码说明.txt」）
  "name": "中文",                         // 下拉框里显示的语言名
  "texts": {                             // 翻译键值对（key 要和现有语言包保持一致）
    "gui.title": "🌍 地球参数",
    "param.shieldOpacity": "护罩透明度",
    ...
  }
}
```

- `code`：BCP 47 语言标签（如 `zh-CN` / `en-US`）。
- `name`：语言切换下拉框里显示的名称（如「中文」「English」）。
- `texts`：全部界面文本的键值对。**缺失的 key 会自动回退到 `zh-CN`**，不会显示裸键。
- `city.` 开头的 key 是城市显示名（如 `"city.东京": "Tokyo"`），用于飞线表格下拉和城市标注。

### 三、新增一种语言（3 步）

1. 复制 `zh-CN.json` 改名为例如 `ja-JP.json`。
2. 改 `code` 为 `ja-JP`、`name` 为 `日本語`，`texts` 改成对应翻译。
3. 放到 `Languages/` 文件夹 → 点右上角「⟳ 刷新语言列表」（或刷新页面）→ 下拉框出现新语言，选中立即生效。

### 四、切换与持久化

- 右上角下拉框实时切换，所有界面文本、lil-gui 面板、城市标注、飞线表格随切换立即更新。
- 选择的语言保存在浏览器 `localStorage`，刷新/重开自动恢复。
- 语言切换时会**销毁并按当前语言重建** lil-gui 参数面板，因此所有控件名、分组名、下拉选项都会更新为当前语言。

## 🧠 技术要点（简述）

- **地球**：`ShaderMaterial` 自定义 GLSL —— 白天/夜晚贴图按「太阳方向与法线点积」经 `smoothstep` 混合；晨昏线附近叠加金色暖调；亮度随昼夜因子变化。
- **法线贴图**：切线空间法线映射（`computeTangents` + TBN 矩阵），把贴图法线扰动后转到世界空间参与光照。
- **护罩**：`ShaderMaterial` + 菲涅尔边缘 + 高斯能量带门控 + 圆周滚动方向可调，能量带沿纬度从北极扫到南极。
- **护罩贴图**：用 Canvas 程序化生成大量**交错八边形**的矢量风图案，`RepeatWrapping` 无缝平铺。
- **星空闪烁**：通过随机调整整球材质 `opacity` 实现。
- **动态飞线**：`quadratic/cubic bezier` 或球面大圆 + 径向抬高的弧线采样点；轨道用 `TubeGeometry`，飞线用 `Points` + `aIndex/uTime` 着色器只显示一段移动的"彗星"；终点用 `TubeGeometry`（法线方向）+ 高度渐变 + 半径扩展做**圆形扩散波**。
- **参数持久化**：`localStorage` 保存 + `controllersRecursive().forEach(c => c.updateDisplay())` 刷新面板。

详细推导与 GLSL 逐行讲解见 **[docs/Three.js-3D-Earth-技术文档.md](docs/Three.js-3D-Earth-技术文档.md)**。
