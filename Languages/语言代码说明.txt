语言代码说明（BCP 47 / IETF 语言标签）
=========================================

语言包文件名和 JSON 里的 code 字段遵循国际标准语言标签（BCP 47 / IETF）：

    格式：语言代码(ISO 639-1) - 地区代码(ISO 3166-1)
    示例：ja-JP = ja(日语) + JP(日本) = 日语（日本）

为什么要「语言 + 地区」两个？
    同一种语言在不同地区写法/用词不同：
      zh-CN 简体中文        zh-TW 繁体中文
      en-US (color)         en-GB (colour)
      pt-BR 巴西葡语        pt-PT 欧洲葡语

常见语言代码对照表：
    zh-CN  简体中文        zh-TW  繁体中文
    en-US  英语(美国)      en-GB  英语(英国)
    ja-JP  日语            ko-KR  韩语
    de-DE  德语            fr-FR  法语
    ru-RU  俄语            es-ES  西班牙语
    it-IT  意大利语        pt-BR  葡萄牙语(巴西)
    vi-VN  越南语          th-TH  泰语

新增一种语言（3 步）：
    1. 复制 zh-CN.json 改名为例如 ja-JP.json
    2. 改 code 为 ja-JP、name 为 日本語，texts 改成对应翻译
       （texts 里的 key 必须和其它语言包保持一致，缺失项会自动回退到 zh-CN）
    3. 放到本文件夹（Languages）下
       → 应用里点右上角「⟳ 刷新语言列表」（或刷新页面）
       → 下拉框出现新语言，选中立即生效
